# Pieach Limited — multi-page property website

This is a responsive, static website concept inspired by the editorial structure and restrained architectural style of Lenval Properties. It is branded for Pieach Limited and uses replacement stock photography from Unsplash.

## Pages included
- `index.html` — homepage
- `about.html` — company story, values and approach, with a Meet the Team link
- `team.html` — team profiles, roles, biographies and working principles
- `projects.html` — portfolio listing
- `gallery.html` — filterable, auto-advancing horizontal carousel with manual arrows, pause/play, touch swipe, progress indicator, and a full-screen slideshow/lightbox with keyboard navigation
- `project-s.html` — residential project detail
- `project-j.html` — residential project detail
- `the-den.html` — commercial project detail
- `contact.html` — contact page with email-app handoff form
- `privacy.html` — starter privacy notice
- `styles.css` — responsive visual system and layouts
- `app.js` — shared navigation, mobile menu, footer year, contact form interaction, gallery carousel and full-screen slideshow
